## Inserting the tags

A mention is not text. Pasting either URL into the post body produces a plain
link, not a tag, and notifies nobody.

1. Paste the post from `linkedin_post.txt` into the LinkedIn composer. The names
   are written out as ordinary text.
2. Delete the words `INSTANT Software Solutions`, type `@INSTANT`, and pick
   **INSTANT Software Solutions** from the dropdown. Repeat for the second
   occurrence.
3. Delete `Eng. Jana Hatem`, type `@Jana`, and pick her profile from the
   dropdown. Keep the `Eng.` title before the tag if you want it shown.
4. Each name should turn into styled, clickable text. If it stays plain, the tag
   did not register — undo and retry.
5. Before posting, click each tag in the preview and confirm it opens the URL
   above.

## Why this was not automated

No Chrome browser is connected to this session, so there is no authenticated
LinkedIn composer available. Even with one, LinkedIn resolves mentions only
through the composer's own autocomplete, so the selection has to be made in the
interface.
